A cozy little game about one small leaf, and the natural disaster about to ruin its day.

**Play:** grab a build for Windows, Mac, Linux or the web from [Releases](https://github.com/ethandacat/make-a-leaf/releases/latest), or open `project.godot` in Godot 4.7 and press F5.
